# Server-performance-stats

This is a bash script which can be executed on any linux targeted machine to generate current status of various performance factors.

## Getting Started

1. **Clone the repository**
    ```
    git clone https://github.com/ashking2002/Server-performance-stats.git
    ```

2. **Make the script executable**
    ```
    chmod +x allstats.sh
    ```
3. **Execute the script**  
    ```
    ./allstats.sh
    ```
